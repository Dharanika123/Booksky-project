# 📚 BookSky

BookSky is a simple JavaScript DOM project that allows users to manage books.

## Features
- ➕ Add a new book
- 🗑️ Delete a book
- 📝 Popup form for entering book details
- 🎨 Responsive and clean UI using HTML & CSS
- ⚡ Dynamic DOM manipulation with JavaScript

## Technologies Used
- HTML5
- CSS3
- JavaScript (DOM)

## What I Learned
- DOM Manipulation
- Event Listeners
- Creating and removing elements dynamically
- Handling forms
- CSS positioning and styling

## Future Improvements
- Edit book details
- Save books using Local Storage
- Search books
